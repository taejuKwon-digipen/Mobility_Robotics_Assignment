# 🚀 문제2. 버튼 입력으로 LED 제어하기

## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 제어 / 디지털 입력, 조건문, 버튼 이벤트 처리 |
| 중요도 | ⭐⭐⭐ |
| 난이도 | ⭐ |
| 예상 소요 시간 | 40분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- 디지털 입력 신호 처리
- 조건문을 활용한 분기 로직 설계
- 버튼 회로 구성 및 디바운싱(채터링 방지) 개념 이해

**Soft Skill**
- 입력 이벤트가 처리되는 전체 흐름을 그려보는 능력
- 문제 발생 시 원인을 좁혀가는 디버깅 절차 수립
- 사용자가 버튼을 누르는 상황을 가정한 시스템적 사고

---

## 📌 배경 설명

자동차의 비상등 스위치나 창문 개폐 버튼, 로봇의 수동 조작 버튼은 모두 디지털 입력 신호를 통해 동작을 인식한다.

이번 실습에서는 버튼을 눌렀을 때 발생하는 신호를 감지하고, 이를 프로그램 내부에서 해석해 처리하는 로직을 구성해 본다. 이는 사용자의 명령을 받아들이고 그에 반응하는 입력 인터페이스의 기본 형태이며, 이후 차량 제어 장치나 로봇의 명령 수신 기능을 만드는 토대가 된다.

---

## 📌 학습 범위

### 사전 배경 지식
- 스위치의 동작 원리와 순간 접촉식 회로의 구성 방식
- 디지털 입력에서 HIGH/LOW 신호가 의미하는 바
- 풀업(Pull-up) / 풀다운(Pull-down) 저항의 개념과 회로도 작성법

### 핵심 학습 내용
- GPIO를 입력 모드로 설정하고 디지털 신호를 읽어오는 방법
- `if` 조건문으로 입력 상태에 따라 분기 처리하는 방법
- 입력 상태 변화에 맞춰 출력을 동적으로 바꾸는 흐름 설계
- 하드웨어 입력이 불안정할 수 있다는 점을 고려한 디바운싱 기초 개념

### 추가로 알아두면 좋은 지식
- 입력 → 조건 판단 → 반응으로 이어지는 사용자 입력 처리 흐름
- 아두이노 내장 풀업 저항 활용법 (`INPUT_PULLUP`)
- 하드웨어적 디바운싱과 소프트웨어적 디바운싱의 차이 비교

---

## 📌 수행 목표

### 핵심 목표
버튼의 입력 상태에 따라 LED 상태를 실시간으로 바꾸는 프로그램을 구현한다.

### 세부 학습 목표
- 입력 장치의 신호를 소프트웨어로 읽고 해석하는 방법 익히기
- 조건문을 이용해 입력에 반응하는 제어 구조 설계하기
- 회로 구성과 프로그램 동작이 어떻게 맞물리는지 이해하기
- 반응형 제어 시스템의 기본이 되는 논리적 처리 방식 익히기

### 최종 산출물
- [X] 버튼을 누르면 LED가 켜지고, 손을 떼면 꺼지는 동작
- [X] 버튼 입력 상태를 시리얼 모니터로 출력해 확인 가능하도록 구성

---

## 📌 수행 절차

1. **회로 구성**
   버튼을 디지털 입력 핀에 연결하고, 신호가 안정적으로 인식되도록 풀업 또는 풀다운 저항을 설계한다.

2. **디지털 입력 상태 해석 구조 설계**
   버튼이 눌렸는지 여부를 판단하는 조건 흐름을 설계한다. 버튼을 눌렀을 때 신호가 HIGH가 되는 구성인지 LOW가 되는 구성인지에 따라 분기 로직을 다르게 작성한다.

3. **LED 반응 조건 설계**
   버튼 상태에 따라 LED를 켜거나 끄도록 출력 제어 조건을 구성한다. (예: "버튼이 눌린 상태면 LED ON, 아니면 OFF")

4. **상태 출력 구조 설계**
   현재 입력 상태나 LED 상태를 시리얼 로그로 확인할 수 있도록 출력 위치를 배치한다.

5. **불안정 입력 처리 고려 (선택)**
   버튼에서 흔히 발생하는 채터링(chattering) 현상에 대응하기 위해 간단한 디바운싱 로직이나 딜레이를 어디에 넣을지 설계에 포함한다.

6. **동작 검증 및 반복 테스트**
   회로와 코드가 의도대로 동작하는지 확인하고, 빠지거나 잘못된 조건이 있으면 로직을 다시 점검한다. 버튼이 눌리지 않거나 배선이 잘못된 경우에도 프로그램이 예외 없이 안정적으로 동작해야 한다.

7. **토론 및 응용 아이디어 제안 (선택)**

## 📌 결과 예시

버튼을 누르면 LED가 켜지고, 손을 떼면 LED가 꺼진다.

```
Button pressed → LED ON
Button released → LED OFF
```
