# 아두이노 기초 정리 (LED 점멸 실습 기준)

## 시뮬레이션 화면에서 보이는 것

- **"13 OUT Low"** — 13번 핀이 `OUTPUT` 모드로 설정되어 있고, 지금 순간은 `LOW`(꺼짐) 상태라는 뜻. 코드의 `pinMode(LED_PIN, OUTPUT)`와 `digitalWrite(LED_PIN, LOW)` 결과가 그대로 표시되는 것.
- **보드 오른쪽의 "L" 표시등** — 13번 핀에는 아두이노 우노 보드 자체에 내장된 LED가 이미 연결되어 있음. 외부 LED를 따로 안 붙여도 이 보드 위의 "L" 램프로 동작 확인이 가능함.
- **"ON" 초록불** — LED 상태가 아니라 보드에 전원이 들어왔다는 표시등(전원 LED).
- **TX/RX (UART0)** — `Serial.begin(9600)`, `Serial.println()`이 사용하는 통신 핀. 컴퓨터와 시리얼 모니터로 데이터를 주고받을 때 깜빡임.
- **"Floating"이라고 써있는 나머지 핀들** — 지금 코드에서 사용하지 않은 핀이라 아무것도 연결되지 않은 상태.

## 아두이노 보드 구역별 역할

| 구역 | 역할 |
|---|---|
| DIGITAL 핀 (0~13) | ON/OFF 신호를 내보내거나(출력) 받는(입력) 핀. LED, 버튼, 센서 등에 연결 |
| ANALOG IN (A0~A5) | 가변저항, 조도센서처럼 값이 연속적으로 변하는 걸 읽는 핀 |
| POWER | 5V, 3.3V, GND(그라운드/-극) 등 전원 공급용 |
| USB 포트 | 컴퓨터와 연결해 코드 업로드 + 전원 공급 + 시리얼 통신 |
| 칩(가운데 검은 부품) | 실제 코드가 실행되는 마이크로컨트롤러(두뇌) |

## 코드 4줄이 하는 일

```cpp
pinMode(13, OUTPUT);       // 13번 핀을 출력용으로 쓰겠다고 선언
digitalWrite(13, HIGH);    // 13번 핀에 전기 흘려보내기 (LED 켜짐)
delay(1000);                // 1000ms(1초) 동안 대기
digitalWrite(13, LOW);     // 전기 끊기 (LED 꺼짐)
```

이 4가지 함수(`pinMode`, `digitalWrite`, `delay`, 그리고 `Serial.println`)만 이해하면 이 과제 수준의 아두이노 코드는 대부분 읽고 쓸 수 있다. 나머지는 이 조합의 응용이다.
