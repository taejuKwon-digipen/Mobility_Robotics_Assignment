## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 출력 제어 / GPIO, LED |
| 중요도 | ⭐⭐⭐ |
| 난이도 | ⭐ |
| 예상 소요 시간 | 30분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- GPIO 출력 핀 제어
- 지연 시간을 이용한 타이밍 제어
- 회로 배선 구성 및 핀 배치도 활용

**Soft Skill**
- 단계별 사고력
- 논리적인 흐름 설계
- 기본적인 디버깅 감각

---

## 📌 배경 설명

모빌리티 시스템은 경고등, 방향지시등, 상태 표시등처럼 다양한 출력 장치로 시스템 상태를 사용자에게 알려준다.
로봇 시스템 역시 오류 알림이나 상태 피드백을 시각적으로 보여주는 데 LED를 자주 사용한다.

이번 실습에서는 Arduino 보드의 디지털 핀으로 LED를 켜고 끄는 가장 기본적인 제어를 직접 구현해 보면서, 차량·로봇 시스템의 상태 표시 장치를 만드는 데 필요한 기초를 다진다.

---

## 📌 학습 범위

### 사전 배경 지식
- 전압, 전류, 저항, LED 같은 회로 구성 요소의 동작 원리
- 아두이노 디지털 핀의 기능과 핀 번호 체계
- 브레드보드의 구조와 배선 방법

### 핵심 학습 내용
- `pinMode(pin, mode)`로 핀을 입력/출력 모드로 설정하는 방법
- `digitalWrite(pin, HIGH/LOW)`로 ON/OFF 신호를 출력하는 방법
- `delay(ms)`로 시간 지연을 주어 프로그램 흐름을 조절하는 방법
- `loop()` 반복 구조 안에서 상태가 계속 바뀌는 동작을 구현하는 방식
- `Serial.begin()`, `Serial.println()` 등 시리얼 출력을 활용한 기초 디버깅

### 추가로 알아두면 좋은 지식
- LED 극성 구분법 (긴 다리가 애노드)
- 전류 제한 저항(330Ω~1kΩ)이 필요한 이유와 계산 방법
- MCU와 외부 장치 간 전압 차이(3.3V vs 5V) 이해
- 타이밍 함수와 비동기 제어 구조 (이후 학습 예고)

---

## 📌 수행 목표

### 핵심 목표
LED를 제어해 보면서 임베디드 시스템의 디지털 출력 원리를 익히고, 회로와 코드가 서로 어떻게 맞물려 동작하는지 실습을 통해 이해한다.

### 세부 학습 목표
- 하드웨어 구성과 소프트웨어 코드가 어떻게 연결되는지 파악
- 아두이노에서 GPIO 핀을 출력으로 설정하고 주기적으로 신호를 내보내는 과정을 직접 구현
- 지연 함수로 시간을 제어하며 동작 흐름을 조절하는 기초 감각 익히기
- 시리얼 로그로 상태를 확인하며 디버깅을 경험

- [X] 동작을 확인할 수 있는 영상 또는 사진 자료
