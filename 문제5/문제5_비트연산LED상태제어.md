# 🚀 문제5. 비트 연산을 활용한 LED 상태 제어

## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 제어 / 포트 제어, 비트 연산, 멀티 GPIO 출력 |
| 중요도 | ⭐⭐⭐ |
| 난이도 | ⭐⭐⭐⭐ |
| 예상 소요 시간 | 60분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- 비트 마스크와 시프트 연산에 대한 이해
- 여러 핀의 상태를 하나의 값으로 압축해 관리하는 포트 기반 제어

**Soft Skill**
- 여러 상태를 하나의 값으로 묶어보는 추상화 사고
- 더 적은 코드로 같은 결과를 내는 최적화된 구조 설계
- 반복되는 조건문을 줄여 복잡도를 낮추는 전략 수립

---

## 📌 배경 설명

센서나 표시 장치의 개수가 늘어날수록 단순 반복문이나 if문만으로는 관리가 번거로워진다. 실제 제품에서는 여러 LED의 상태를 하나의 정수 값에 비트 단위로 압축해서 저장하고, 각 비트를 해석해서 출력 핀을 제어하는 방식을 흔히 사용한다.

이번 실습에서는 4개의 LED 상태를 하나의 정수로 표현하고, 그 값의 각 비트를 읽어서 GPIO 핀을 제어하는 구조를 만들어본다.

---

## 📌 학습 범위

### 사전 배경 지식
- 2진수와 비트 단위 개념, MSB/LSB가 무엇인지
- `&`, `|`, `<<`, `>>` 같은 비트 연산자가 동작하는 방식
- 비트마스크(Bitmask)의 의미와 활용법

### 핵심 학습 내용
- 정수 하나의 각 비트로 여러 상태를 동시에 표현하는 방법
- 비트 연산으로 각 비트가 켜져 있는지 판단해서 GPIO 출력에 반영하는 방법
- 배열 없이 비트 연산과 반복문만으로 다중 출력을 구조화하는 방법

### 추가로 알아두면 좋은 지식
- 연산 기반 제어가 메모리와 성능 측면에서 갖는 장점
- 일반적인 반복문 기반 제어 방식과 비트 연산 제어 방식의 차이 비교
- 하드웨어 제어를 추상화하는 기법의 기초 개념

---

## 📌 수행 목표

### 핵심 목표
LED 상태를 4비트 정수 하나로 표현하고, 이 값을 비트 연산으로 해석해서 각 LED를 제어한다.

### 세부 학습 목표
- 정수 하나로 여러 장치의 상태를 효율적으로 관리하는 방법 익히기
- 특정 비트의 상태를 추출해 제어 로직에 적용하는 방법 익히기
- 포트 단위 제어의 효율성과 구조적인 제어 로직을 작성하는 경험 쌓기

### 최종 산출물
- [X] 사용자가 입력한 정수값(0~15)에 따라 4개의 LED가 각 비트 상태에 맞게 ON/OFF되는 시스템

---

## 📌 수행 절차

1. **회로 구성**
   LED 4개를 각각 디지털 핀에 연결하고, 공통 GND에 연결한다. 각 핀에 대응하는 LED 번호와 GPIO 번호를 표로 정리해서 관리한다.

2. **상태값 입력 구조 설계**
   LED 제어 상태를 4비트 정수 하나로 저장하도록 설계한다. 값을 올리는 방법은 자유롭게 선택 가능하다.
   - 버튼 하나로 값을 1씩 증가시키는 방식
   - DIP 스위치로 직접 값을 설정하는 방식
   - 시리얼 입력으로 외부에서 값을 받는 방식 (선택, 확장 가능)

3. **비트 추출 로직 설계**
   각 비트가 1인지 0인지 판별하기 위해 `bitRead()` 함수나 `(val >> i) & 0x01` 방식을 사용한다. 비트 위치에 따라 해당 핀을 ON/OFF할지 결정하는 구조를 만든다.

4. **LED 출력 제어 설계**
   추출한 각 비트 값에 따라 대응하는 GPIO 핀을 켜거나 끈다. 중복되는 조건문 없이 반복문과 비트 연산의 조합만으로 구현한다.

5. **시리얼 로그 및 상태 검증**
   현재 입력된 정수값, 각 비트 상태, 각 LED의 상태를 시리얼로 출력한다. 실제 LED 상태와 로그가 일치하는지 비교하며 검증한다.

6. **토론 및 응용 아이디어 제안 (선택)**

---

## 📌 결과 예시

입력값 `0b1101` (10진수 13) → LED 1, 3, 4 ON / LED 2 OFF

**시리얼 출력**
```
Input: 13 (0b1101)
LED 1: ON
LED 2: OFF
LED 3: ON
LED 4: ON
```

## 📌 보너스 과제 (선택)
- 시리얼 입력으로 0~15 범위의 정수를 받아 실시간으로 LED 상태를 제어하도록 확장
- 4비트 LED 상태를 나타내는 상태표(HEX ↔ LED 패턴)를 출력하는 디버그 모드 추가
- LED마다 역할(예: 경고, 대기, 동작 중, 오류)을 부여하고, 상태값에 따라 해당 라벨을 시리얼로 출력
