# 📌 버튼 입력 참고자료

## 1. 풀업 / 풀다운 저항

디지털 입력 핀은 버튼을 누르지 않은 동안 아무 곳에도 연결되지 않은 상태(플로팅)가 되면 전압이 불안정해져 HIGH/LOW 값이 노이즈에 따라 제멋대로 튈 수 있다. 풀업/풀다운 저항은 버튼이 눌리지 않았을 때의 기본 전압 상태를 고정해주는 역할을 한다.

**풀업(Pull-up)**
- 핀을 5V(또는 3.3V)에 저항으로 묶어놓아 평소에는 HIGH
- 버튼을 누르면 GND로 연결되어 그 순간 LOW로 바뀜
- 즉, **안 눌렀을 때 HIGH, 눌렀을 때 LOW**
- 아두이노는 `pinMode(pin, INPUT_PULLUP)`으로 내부 저항을 활성화할 수 있어 외부 저항 없이 구현 가능

**풀다운(Pull-down)**
- 핀을 GND에 저항으로 묶어놓아 평소에는 LOW
- 버튼을 누르면 5V로 연결되어 그 순간 HIGH로 바뀜
- 즉, **안 눌렀을 때 LOW, 눌렀을 때 HIGH**
- 아두이노에는 내부 풀다운 저항이 없어서 외부에 저항(보통 10kΩ)을 직접 연결해야 함

어떤 방식을 쓰느냐에 따라 조건문의 HIGH/LOW 판단이 반대로 뒤집히므로, 회로 구성과 코드의 조건문이 서로 일치하는지 항상 확인해야 한다.

## 2. 버튼 입력 예제 코드

외부 풀다운 저항을 사용하는 기본형 예시 (라이브러리 없이 기본 함수만 사용):

```cpp
const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT);   // 외부 풀다운 저항 사용 전제
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == HIGH) {      // 풀다운 구성이면 눌렀을 때 HIGH
    digitalWrite(LED_PIN, HIGH);
    Serial.println("Button pressed -> LED ON");
  } else {
    digitalWrite(LED_PIN, LOW);
    Serial.println("Button released -> LED OFF");
  }
}
```

`INPUT_PULLUP`을 사용하는 경우에는 `pinMode(BUTTON_PIN, INPUT_PULLUP)`으로 바꾸고, 조건도 `buttonState == LOW`일 때를 눌린 상태로 반대로 판단해야 한다.

## 3. 디바운싱(디바운스) 개념

버튼 스위치는 눌리는 순간 기계적 접점이 미세하게 떨리면서(채터링, chattering) 짧은 시간 동안 HIGH/LOW 신호가 여러 번 튀는 현상이 발생한다. 이를 그대로 읽으면 한 번 눌렀는데도 여러 번 눌린 것으로 잘못 인식될 수 있다.

**간단한 해결법 (딜레이 방식)**

```cpp
if (digitalRead(BUTTON_PIN) == HIGH) {
  delay(20);  // 20ms 정도 대기 후 다시 확인 (채터링 구간 회피)
  if (digitalRead(BUTTON_PIN) == HIGH) {
    // 진짜로 눌린 것으로 인정
  }
}
```

이 방식은 `delay()`로 `loop()` 전체 흐름을 잠시 멈추기 때문에 간단하지만 임시방편에 가깝다. 더 발전시키면 `millis()`로 경과 시간을 측정해 `delay()` 없이 처리하는 비차단(non-blocking) 디바운싱 방식으로 개선할 수 있다.
