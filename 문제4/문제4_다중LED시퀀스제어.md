# 🚀 문제4. 다중 LED 시퀀스 제어

## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 제어 / 다중 출력, 순차 제어, LED 시퀀스 |
| 중요도 | ⭐⭐⭐ |
| 난이도 | ⭐⭐⭐ |
| 예상 소요 시간 | 60분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- 여러 개의 GPIO 핀을 동시에 다루는 방법
- 배열과 반복문을 이용한 출력 제어
- 타이밍 기반으로 순서를 만드는 시퀀스 설계

**Soft Skill**
- 시간 흐름을 기준으로 로직을 짜는 사고방식
- 패턴(순서/방향)을 코드로 옮기는 설계 감각
- 실행 순서가 꼬였을 때 원인을 추적하는 디버깅

---

## 📌 배경 설명

실제 시스템은 버튼 하나, LED 하나로 끝나지 않는다. 자동차는 여러 스위치의 상태를 동시에 감지해 조명이나 기능을 조합해서 제어하고, 로봇 역시 여러 센서와 조작 입력을 종합해 복합적으로 반응한다.

이번 실습에서는 여러 개의 LED를 순서대로 켜고 끄는 로직을 만들어보면서, 여러 출력을 한 번에 다루는 병렬 제어의 기초 감각을 익힌다.

---

## 📌 학습 범위

### 사전 배경 지식
- 여러 GPIO 핀을 동시에 설정하고 제어하는 구조
- 여러 출력 장치를 한 회로에 연결할 때 전류 분산과 관련해 주의할 점
- 지연 함수(`delay`)가 프로그램 흐름에 미치는 영향과 그로 인한 부작용

### 핵심 학습 내용
- 배열(Array)에 LED 핀 번호를 담아 구조적으로 관리하는 방법
- `for`, `while` 반복문으로 순차 제어 로직을 짜는 방법
- `delay()`로 타이밍을 조절해 간단한 애니메이션처럼 보이게 만드는 방법
- "오른쪽으로 순서대로 켜지고 왼쪽으로 순서대로 꺼지는" 식의 동작 패턴을 로직으로 옮기는 방법

### 추가로 알아두면 좋은 지식
- `delay()` 기반 제어가 길어질 때 생기는 한계와, 이후 배울 비동기 처리의 필요성
- 여러 장치를 동시에 연결할 때 전류 소비와 전원 부하를 고려해야 하는 이유
- 여러 장치를 한 번에 다루기 좋은 구조적인 코딩 습관

---

## 📌 수행 목표

### 핵심 목표
3개 이상의 LED가 순서대로 켜지고 꺼지는 시퀀스 제어 시스템을 설계한다.

### 세부 학습 목표
- 여러 출력 장치를 배열과 반복문으로 효율적으로 다루는 방법 익히기
- 시간 지연을 활용해 LED 점등 패턴을 만드는 설계 능력 기르기
- 정해진 순서대로 정확하게 반응하는 타이밍 기반 흐름 구현하기

### 최종 산출물
- [X] LED 4개가 한쪽 방향으로 하나씩 켜졌다가, 반대 방향으로 하나씩 꺼지는 시퀀스
- [X] LED 상태 변화를 시리얼 로그로 출력

---

## 📌 수행 절차

1. **다중 회로 구성**
   LED 4개와 저항을 브레드보드에 연결하고, 각 LED를 서로 다른 디지털 핀에 연결한다. GND는 공통으로 묶고, 각 핀은 GPIO 출력으로 연결한다.

2. **핀 설정 구조 설계**
   4개의 디지털 핀을 각각 OUTPUT으로 설정한다. 핀 번호는 배열에 저장해두고, 반복문으로 한 번에 다룰 수 있도록 구성한다.

3. **시퀀스 점등 로직 구상** (자유롭게 설계)
   한쪽 끝(예: 1번)에서 반대쪽 끝(예: 4번) 방향으로 LED를 하나씩 순서대로 켠다. 각 점등 사이에 짧은 지연을 넣어 애니메이션처럼 보이게 하고, 이어서 반대 방향으로 하나씩 소등한다.

4. **타이밍 기반 반복 구성**
   `for` 반복문과 `delay()`로 동작 순서를 제어한다. 전체 시퀀스를 일정 간격으로 반복 실행할 수 있도록 구성한다.

5. **디버깅 및 상태 출력 설계**
   LED가 켜지거나 꺼질 때마다 몇 번 LED인지 시리얼로 출력해서 동작을 확인한다. 실제 LED 동작 순서가 의도한 대로인지 눈으로 보는 것과 로그 두 가지로 검증한다.

6. **토론 및 응용 아이디어 제안 (선택)**

## 📌 결과 예시

**LED 점등 순서**
```
[ON] LED 1 → LED 2 → LED 3 → LED 4
[OFF] LED 4 → LED 3 → LED 2 → LED 1
```

**시리얼 로그**
```
LED 1 ON
LED 2 ON
...
LED 4 OFF
...
```

## 📌 보너스 과제 (선택)
- 시퀀스가 자동으로 계속 반복되는 대신, 버튼을 누를 때마다 한 단계씩만 진행하는 방식으로 변경
- LED가 양쪽 방향으로 왔다갔다 하며 점등/소등되는 "왕복" 시퀀스 구성
- 시리얼 입력으로 시퀀스 속도를 사용자가 직접 조절할 수 있는 기능 추가
