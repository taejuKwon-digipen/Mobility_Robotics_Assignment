# 🚀 문제3. 버튼 토글 스위치 구현

## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 제어 / 디지털 입력, 상태 전환, 토글 로직 |
| 중요도 | ⭐⭐⭐ |
| 난이도 | ⭐⭐⭐ |
| 예상 소요 시간 | 50분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- 상태 기반 제어 설계
- 버튼 이벤트를 신호가 아닌 상태 변화로 해석하는 방법
- 플래그(flag) 변수를 이용한 상태 관리

**Soft Skill**
- 상태가 전이되는 흐름을 구조적으로 설계하는 사고
- 입력 이벤트를 단계별로 추적하는 디버깅 습관
- 하드웨어 신호와 소프트웨어 상태를 분리해서 보는 관점

---

## 📌 배경 설명

버튼을 누르고 있는 동안만 반응하는 제어는 실제 제품에서는 거의 쓰이지 않는다. TV 리모컨의 전원 버튼이나 방 조명 스위치처럼, 대부분의 장치는 버튼을 한 번 누를 때마다 상태가 반전되는 **토글(toggle)** 방식으로 동작한다.

이번 실습에서는 버튼을 누를 때마다 LED의 상태가 뒤집히는 시스템을 만든다. 핵심은 버튼의 물리적 신호(눌림/안눌림) 자체가 아니라, 그 신호를 해석해서 내부에 **상태값으로 기억하고 유지하는 논리**를 설계하는 데 있다.

---

## 📌 학습 범위

### 사전 배경 지식
- 순간 접촉식 스위치가 눌렸을 때 신호가 어떻게 바뀌는지
- 하드웨어에서 들어온 신호와 소프트웨어 내부 상태를 동기화한다는 개념
- 상태 머신(Finite State Machine)의 기본 아이디어

### 핵심 학습 내용
- 플래그 변수(또는 상태 변수)로 현재 상태를 저장하고 유지하는 방식
- 조건문과 논리 연산자로 상태 전이 로직을 구성하는 방법
- 버튼을 누르는 "그 순간"에만 상태가 바뀌도록 처리하는 엣지 트리거(edge trigger) 개념
- "누르고 있는 동안 유지되는 상태"와 "누를 때마다 반전되는 토글"의 차이

### 추가로 알아두면 좋은 지식
- 상태 전이 다이어그램을 직접 그려보면서 동작 흐름을 구조화하는 연습
- 신호의 변화(Edge Detection)를 감지하는 것과 단순히 현재 값을 읽는 것의 차이
- 버튼을 누를 때 발생하는 하드웨어 노이즈로 인한 중복 입력과 디바운싱 처리

---

## 📌 수행 목표

### 핵심 목표
버튼을 누를 때마다 LED 상태가 반전(ON → OFF, OFF → ON)되는 토글 시스템을 구현한다.

### 세부 학습 목표
- 버튼 입력을 상태 전환의 트리거로 활용하는 방법 익히기
- 이전 상태를 기억했다가 다음 상태를 결정하는 로직 구성하기
- 토글 로직에서 왜 디바운싱/중복 입력 방지가 필요한지 이해하기

### 최종 산출물
- [X] 버튼을 누를 때마다 LED 상태가 반전되는 시스템
- [X] 현재 LED 상태를 시리얼 로그로 출력

---

## 📌 수행 절차

1. **회로 구성**
   버튼과 LED를 각각 디지털 입력 핀과 출력 핀에 연결한다.

2. **토글 동작 정의**
   버튼을 누를 때마다 "현재 상태"를 반전시키는 논리를 구상한다. 이전 상태를 기억할 변수(flag, state 등)를 정의하고, 이 값이 버튼이 눌릴 때마다 ON/OFF로 전환되도록 한다.

3. **입력 신호의 변화 감지 방법 설계**
   버튼을 "누르고 있는 상태"가 아니라 "눌린 그 순간에만" 반응하도록 설계한다. 이를 위해 "이전 버튼 상태"와 "현재 버튼 상태"를 비교하는 구조를 만든다.

4. **LED 출력 상태 설계**
   내부 상태 변수 값에 따라 LED를 ON/OFF하는 조건 분기를 작성한다. 한 번 토글된 상태는 다음 버튼 입력 전까지 그대로 유지되어야 하며, 버튼을 누르지 않는 동안에는 상태가 바뀌면 안 된다.

5. **디버깅 및 테스트 흐름**
   현재 버튼 상태, 내부 상태 변수, LED 상태를 각각 시리얼 로그로 출력해서 디버깅에 활용한다. 버튼을 천천히 반복해서 눌러보며, 누른 순간에만 상태가 바뀌는지 확인한다.

6. **토론 및 응용 아이디어 제안 (선택)**

---

## 📌 결과 예시

LED는 처음에 OFF 상태로 시작한다. 버튼을 누르면 ON, 다시 누르면 OFF, 또 누르면 ON... 이런 식으로 반복된다.

```
Button pressed → LED ON
Button pressed → LED OFF
...
```
