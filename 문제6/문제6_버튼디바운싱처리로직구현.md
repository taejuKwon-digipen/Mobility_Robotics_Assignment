# 🚀 문제6. 버튼 디바운싱 처리 로직 구현

## 📌 개요

| 항목 | 내용 |
|---|---|
| 분야 | 디지털 제어 / 디지털 입력 안정화, 디바운싱, 신호 필터링 |
| 중요도 | ⭐⭐⭐⭐ |
| 난이도 | ⭐⭐⭐ |
| 예상 소요 시간 | 60분 |

---

## 📌 배울 수 있는 역량

**Hard Skill**
- 디지털 신호 노이즈 이해
- 디바운싱 타이밍 로직 설계
- 조건 타이밍 제어

**Soft Skill**
- 신호 안정화 사고
- 사용자 경험 기반 문제 해결
- 동작 신뢰성 강화 설계

---

## 📌 배경 설명

버튼을 눌렀을 때 LED가 깜빡거리거나 여러 번 반응하는 현상이 발생하고 있다. 실제 하드웨어에서는 버튼의 물리적 접촉 불안정으로 인해 수 밀리초 내에 진동(Chattering)이 발생하고, 이를 소프트웨어가 다수의 입력으로 잘못 인식하게 된다.

이번 실습에서는 버튼 입력의 노이즈를 소프트웨어적으로 안정화하는 디바운싱 로직을 설계하여, 사용자 입력이 1회만 정상 인식되도록 구현한다.

---

## 📌 학습 범위

### 사전 배경 지식
- 물리 버튼의 접점 떨림 원리 및 발생 시간
- 디지털 신호가 변화할 때 MCU가 이를 인식하는 방식

### 핵심 학습 내용
- 소프트웨어 기반 디바운싱 구현 방식 (지연 기반 방식, 상태 기반 방식)
- 조건문과 시간 비교를 통한 짧은 기간 내 중복 입력 차단 로직 설계
- `millis()` 함수 기반의 시간 비교 구조

### 추가로 알아두면 좋은 지식
- 하드웨어 디바운싱(콘덴서, IC)과 소프트웨어 디바운싱의 차이
- 인터럽트 기반 디바운싱 처리 구조 예비 학습
- 사용자 인터페이스 신뢰성에 대한 고려

---

## 📌 수행 목표

### 핵심 목표
버튼을 누를 때 발생하는 신호 노이즈를 소프트웨어적으로 필터링하여, LED가 정확히 한 번만 반응하도록 디바운싱 로직을 설계한다.

### 세부 학습 목표
- 노이즈 발생 시나리오와 이를 인식하는 시스템의 한계 이해
- `millis()` 함수와 조건문을 활용한 시간 기반 디바운싱 로직 구현
- 사용자 입력을 단일 이벤트로 처리하는 상태 관리 구조 설계

### 최종 산출물
- [X] 버튼을 누를 때마다 LED가 정확히 한 번씩만 점멸하는 시스템
- [X] 시리얼 로그를 통해 중복 입력이 발생하지 않음을 검증

---

## 📌 수행 절차

1. **현상 재현**
   기존의 버튼 입력 코드를 사용하여 디바운싱 없는 상태에서 버튼을 누르고, LED가 한 번 이상 깜빡이는 현상을 관찰한다.

2. **디바운싱 방식 설계**
   시간 기반 디바운싱을 적용하기 위한 조건 흐름을 설계한다.
   - 이전 입력 처리 이후 일정 시간이 지나기 전에는 입력을 무시
   - `millis()` 함수를 사용해 버튼이 눌린 시점과 현재 시점을 비교

3. **상태 기반 입력 필터링 구성**
   버튼이 처음 눌렸을 때만 반응하도록 하기 위해 이전 버튼 상태(`lastButtonState`)와 현재 상태를 비교하는 조건문을 추가한다. 한 번의 눌림에 대해 단일 트리거만 발생하도록 논리를 구성한다.

4. **동작 검증 및 시리얼 출력**
   디바운싱 적용 전/후의 LED 반응 차이를 시리얼 로그로 비교한다. 일정 시간 이내의 반복 눌림에 대해 반응하지 않도록 설정한다 (예: 50ms 기준).

5. **토론과 응용 방안 제안 (선택)**

---

## 📌 결과 예시

버튼을 짧게 여러 번 눌러도 LED가 한 번만 반응한다.

**시리얼 출력** (버튼을 두 번 누른 경우)
```
Button pressed -> LED ON
Button pressed -> LED OFF
```
(디바운스 간격 내의 채터링에 대해서는 복수로 프린트가 되지 않아야 함)
